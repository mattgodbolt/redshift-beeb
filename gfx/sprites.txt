# REDSHIFT's sprites, facing right where they face at all.
#
#   sprite <name> <width> <height>      then <height> lines of <width> pixels
#
# Flags: "mirror" if it faces a way (it's stored flipped too); "phase" if
# it belongs to a phase (it gets a dotted ghost, shown out of phase, as the
# next sprite). Widths are multiples of 4 (one MODE 1 byte). '.' is see-through; '1', '2'
# and '3' are logical colours, so they take the band's colours as a sprite
# moves down the screen (gfx/tiles.txt says what each is for). A comment is
# a whole line starting with '#'.
