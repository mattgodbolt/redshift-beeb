# REDSHIFT's tiles: 8x8 pixels each, in MODE 1's logical colours.
#
#   tile <key> <name> [flags...]      then 8 lines of 8 pixels
#   variant <key> <when>              then 8 lines: how tile <key> looks where <when> holds
#   alt <key> <when>                  then 8 lines: another look for that <when>, used now and then
#
# The key is the character that stands for the tile in rooms/rooms.txt
# ("space" for the empty tile, which must come first). Pixels are '.' (0,
# black) and '1', '2', '3'. What physical colour each shows depends on the
# room's palette bands, so draw with roles, not colours. Every tile keeps
# to them, so that a colour means one thing everywhere:
#   0  air
#   1  the body of anything built: walls, floors, plates, pipes
#   2  its lit edges: the lip of whatever you can stand on, trims
#   3  white: the player, enemies, pickups and lethal tips. In a band of
#      liquid the room makes 3 the liquid's colour, and nothing else there
#      may use it.
# Flags: solid (stands you up and stops you), hazard (kills), breakable
# (a grenade clears it, and the breakable tiles above and below it), red /
# blue (only there in that phase: out of phase it's drawn as a dotted
# outline, and it's neither solid nor a hazard).
#
# A tile's variants are its looks for where it is, chosen when the rooms
# are built (gfxlib.resolve), so a room is drawn with just the keys:
#   up down left right   those sides are open: a solid tile's side is open
#                        to anything not solid in both phases; another
#                        tile's, to any other tile. Join with '+'.
#   deep                 no side is open
#   ceiling              the tile above is solid in both phases
#   tl tr bl br          where it falls on a two by two grid (top left...)
#   exit_left ...        in the edge cell of a room's exit that way
# The first variant that holds is used, or else the tile as written. An
# alt is used instead now and then, at cells picked by a hash of where
# they are ("alt <key> base" for the tile as written).
# A comment is a whole line starting with '#'.
