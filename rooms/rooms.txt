# REDSHIFT's rooms. Edit by hand, or with the level editor (editor/index.html).
#
# room <id>                   starts a room; ids are single words
# name <text>                 shown in the status bar
# exits left=<id> right=<id> up=<id> down=<id>    (- for none)
# start <x> <y>               where a new game starts (the first room only),
#                             in tiles: the player's feet stand on row y + 1
# colours <c1> <c2> <c3>      logical colours 1-3 at the top of the room
# band <line> <logical> <c>   from playfield line 0-175 down, logical 1-3
#                             shows colour c (at most 8; 2 lines apart)
# map                         then 22 lines of up to 32 tiles (gfx/tiles.txt)
# thing <type> <x> <y> [arg]  an enemy or pickup: its top-left, in tiles;
#                             arg 1 faces it left. Types: sentry drone
#                             crawler shard cell grenades life exit
#
# A colour is black red green yellow blue magenta cyan white: the Red Phase's.
# The Blue Phase's is its opposite (red-blue, yellow-cyan, magenta-green)
# unless given after a slash, as in red/white.
